# LaTeX 本科毕业论文审阅技能

本项目是一个专门用于审阅本科 LaTeX 毕业论文的 AI 技能配置，特别适用于基于自定义文档类（如 `hfut.cls`）构建的中文毕业论文。

## 功能特性

### 核心审阅能力

- **全文结构审查**：评估论文整体结构、章节平衡性和本科论文完整性
- **章节深度分析**：检查各章节内容是否充实，是否符合预期的论文角色
- **公式与符号审查**：检查公式引入、符号定义、编号一致性和标点符号
- **图表内容审查**：不仅检查 LaTeX 包装器，还会检查实际图像内容（坐标轴标签、图例、单位等）
- **引用规范检查**：验证文献引用完整性、作者姓名与参考文献条目的一致性
- **术语一致性检查**：确保全文术语使用统一
- **中文学术写作规范**：检查语法、可读性和学术表达

### 审阅输出特性

- **批注式审阅**：使用 `changes` 宏包的 `\comment{...}` 进行精确定位的审阅批注
- **侧边评论框**：使用 `todonotes` 在页面右侧显示评论，保持正文宽度基本不变
- **首页审阅总结**：在审阅版 PDF 的第一页插入审阅摘要报告
- **评审专用布局**：支持右侧扩展页面宽度的评审布局模式

## 审阅工作流程

### 1. 确定审阅范围

- 如果只提供了单个章节，仍会从 `Thesis.tex`、目录和相邻章节名称推断其在整篇论文中的角色
- 如果提供了主文件或完整论文，会先进行全文结构和深度审查，然后再进行句子级别的标注

### 2. 读取配置

检查文档类文件和主文件，确定：
- `changes` 宏包的加载方式
- 侧边评论是否使用 `todonotes`
- 是否启用了专门的审阅模式（如 `reviewlayout`）
- 页面宽度是否在右侧进行了扩展以适应评论

### 3. 构建论文地图

对于可用的主文件，会构建包含以下内容的论文地图：
- 前置部分：封面、中英文摘要、关键词、目录
- 章节大纲
- 章节和段落的大致平衡
- 图、表、公式、算法、引用和参考文献文件

### 4. 结构和深度审查

在进行局部评论之前，先进行结构审查：
- 论文是否包含预期的前置部分、引言、正文、结论、参考文献和必要的附录
- 各章节是否有足够的实质性内容
- 章节顺序、标题和过渡是否与标题、摘要和声称的工作相匹配
- 方法论、实验、实现、结果分析、局限性和未来工作是否出现在预期位置

### 5. 逐段逐句审阅

详细审阅目标章节的每个段落和句子。

### 6. 公式审查

审查每个显示公式、方程、算法表达式和重要的行内符号，检查：
- 引入方式
- 编号
- 引用
- 符号定义
- 单位一致性
- 标点符号
- 符号一致性

### 7. 图表审查

在两个层次上审查每个引用的图或图表：
- **LaTeX 包装器层**：检查 `\caption{}`、`\label{}`、子图顺序、正文中的引用顺序
- **实际图像内容层**：检查坐标轴标签、图例文本、单位、标签语言一致性、打印后可读性、裁剪、模糊、拉伸等问题

### 8. 插入评论

在问题位置精确插入 `\comment{...}` 评论。

### 9. 创建审阅总结报告

为审阅版 PDF 创建或更新首页审阅摘要报告。

### 10. 编译验证

使用以下命令编译：
```bash
latexmk -xelatex -outdir=tmp Thesis.tex
```

验证编译成功，并在必要时检查渲染的 PDF 页面。

## 审阅优先级

### 必须修正或必须验证的问题

默认会对以下问题添加评论：
- 事实性陈述或文献综述缺少引用
- 首次使用缩写未展开
- 影响含义或可读性的语法错误
- 作者姓氏与参考文献条目不匹配
- 损坏或非 ASCII 标签（当项目要求 ASCII 标签时）
- 阻碍理解的图、表或公式问题
- 缺少公式解释、未定义的符号、符号不一致或未引用的编号方程
- 结构单薄的章节或段落，未能完成预期的论文角色
- 各章节中缺少本科论文应有的内容
- 在结果或结论附近出现的无根据的强烈断言

### 可选优化问题

仅在明确增加价值时才评论：
- 轻微的措辞润色
- 不影响理解的小术语清理
- 不影响正确性的重复
- 可选的标题精简
- 不改变正确性或合规性的风格改进

## 评论密度控制

为避免过度标注：
- 每个局部问题优先使用一条高信号评论
- 如果一个句子已有必须修正的评论，跳过同一句子上的次要风格注释
- 默认每段最多一条可选优化评论
- 如果一段已有两条评论，仅在明确必须修正时才添加另一条
- 当多个相邻问题共享一个根本原因时，写一条综合评论而不是多条近似重复的评论

## Preprint 配置模式

对于 `hfut.cls` 风格的工作流程，审阅布局有两层，都以 `preprint` 为中心。

### 1. 文档类文件层

从 `hfut.cls` 使用 `changes` 和 `todonotes`，而不是从章节文件。直接修补 `preprint` 分支。

代表性模式：

```latex
\ifdefstring{\HFUT@mode}{preprint}{
    \RequirePackage[mathlines]{lineno}
    \linenumbers
    \RequirePackage[xcolor=dvipdf,markup=default,todonotes={textsize=scriptsize,textwidth=3.1cm,color=cyan!12,linecolor=cyan!45!black,bordercolor=cyan!45!black}]{changes}
    \setcommentmarkup{\todo{\arabic{authorcommentcount}. #1}}
    \geometry{paperwidth=22.2cm,paperheight=29.7cm}
}
```

### 2. 主文件页宽层

如果用户希望正文宽度保持基本不变，同时仍为侧边 `todo` 框留出空间，不要仅仅缩小 `\textwidth`。而是在 `Thesis.tex` 中向右扩展物理页面宽度。

代表性模式：

```latex
\newgeometry{left=3cm, right=4.2cm, top=2.54cm, bottom=2.54cm}
...
\newgeometry{left=2.8cm, right=4cm, top=3.14cm, bottom=3.14cm}
```

解释：
- 标准 A4 宽度为 `21.0cm`
- 审阅宽度为 `22.2cm`
- 额外的 `1.2cm` 仅添加在右侧
- 这补偿了文档类文件审阅布局的缩减，并为 `todo` 评论提供实际的页面空间

## 评论风格规范

- 默认仅使用 `\comment{...}`
- 使用简洁、直接的导师式评论
- 适当时为评论添加问题标签前缀（参见 `references/review-checklist.md`）
- 除非仓库已经使用或用户要求，否则不假设作者 ID（如 `Advisor`）

## 首页摘要报告

审阅版 PDF 应在论文封面或第一页原始内容之前以简洁的审阅摘要页开始。这仅是审阅工件；除非用户明确要求，否则不要将其包含在最终提交的 PDF 中。

默认实现：
- 在 `Thesis.tex` 旁边创建或更新 `review-summary.tex`
- 在 `\begin{document}` 之后立即引入，在原始论文前置部分之前
- 在项目支持审阅/预印模式时由该模式保护
- 尽可能将摘要保持在一页以内
- 总结审阅期间发现的最高优先级问题

详细内容结构、LaTeX 插入模式和验证步骤见 `references/summary-report.md`。

## 文本审阅优先级

除非用户缩小范围，否则按以下顺序应用：

1. 全文结构、章节平衡和本科论文完整性
2. 各章节或段落中缺少的预期内容
3. 公式、符号、表格和图表规范
4. 事实性陈述或文献综述缺少引用
5. 首次使用缩写展开
6. 作者姓氏和参考文献条目一致性
7. 术语一致性
8. 中文语法和可读性
9. 冗余和段落逻辑

## 编译和验证

进行有意义的审阅编辑后，使用以下命令编译：

```bash
latexmk -xelatex -outdir=tmp Thesis.tex
```

然后验证：
- PDF 成功构建
- 编译成功时评论正确渲染（当用户需要渲染检查时）
- 审阅 PDF 的第一页是审阅摘要报告
- 局部评论仍位于预期问题附近
- 加宽的纸张尺寸和右侧审阅区域仍处于活动状态
- 没有引入新的 LaTeX 硬错误

诸如 `Marginpar moved` 之类的警告在侧边评论中很常见。仅当它们实质上隐藏或分离评论与预期页面上下文时，才将其视为实际渲染问题。

## 编辑约束

- 除非用户明确允许更广泛的干预，否则保留学生的结构
- 不要悄悄重写仅仅是风格性的内容
- 除非用户要求直接修订标记，否则优先使用评论而不是直接更正
- 如果一页上的侧边评论变得过于密集，缩短或删除仅最低优先级的评论，而不是整个审阅标准

## 本科论文规范

不要只检查句子级别的语言。还要检查章节是否满足本科论文的通常标准：

- 该部分是否包含预期包含的内容
- 结构是否足够完整以适应学生论文
- 公式、表格和图表是否得到引入和解释
- 实验是否描述了足够的信息，使读者能够理解比较了什么以及如何比较
- 结论是否总结了工作、局限性和可能的未来工作，而不仅仅是重复断言

## 使用说明

1. 将此技能配置添加到您的 AI 助手
2. 提供要审阅的 LaTeX 论文文件
3. AI 将根据本科论文标准进行全面审阅
4. 生成带有批注的审阅版 PDF
